# Описание основных и связанных таблиц базы Front

## 1. Анализ закупки продукции

**Основная таблица:** `bm_StorageOperations` — содержит складские операции поступления и списания товаров.

| Таблица | Роль | Колонки для связи | Назначение связи |
|---|---|---|---|
| `bm_StorageOperations` | Основная | `DocumentID`, `OperationID`, `ProductID`, `VendorID`, `StorageID` | Связывает складскую операцию с документом, типом операции, товаром, поставщиком и складом |
| `bm_JournalBarnetDocs` | Связанная | `ID` | `ID = bm_StorageOperations.DocumentID`: документ, к которому относится операция |
| `bm_StorageOperationsType` | Связанная | `ID` | `ID = bm_StorageOperations.OperationID`: расшифровка типа складской операции |
| `product` | Связанная | `id` | `id = bm_StorageOperations.ProductID`: товар, участвующий в операции |
| `vendors` | Связанная | `id` | `id = bm_StorageOperations.VendorID`: поставщик товара |
| `storages` | Связанная | `id` | `id = bm_StorageOperations.StorageID`: склад, на котором выполнена операция |
